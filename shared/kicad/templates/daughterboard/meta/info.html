OSUSat Backplane Test Board Template

CubeSat Backplane Expansion Card Template (v1)

This KiCad project template provides a standardized baseline for developing OSUSat CubeSat expansion cards, test boards, and payload modules compatible with the OSUSat Backplane architecture.

Key Technical Features

  • Inter-Board Connector Interface: Pre-configured hierarchical schematic sheet (inter_board_connector.kicad_sch) featuring the Samtec TFM-120-X1-XXX-D-RA 40-pin connector (J1).
  • Standardized Bus Architecture: Fully labeled signal nets including CAN bus (CAN_MAIN_P, CAN_MAIN_N), SPI bus (SPI_SCK, SPI_MOSI, SPI_MISO, SPI_CS), I2C bus (I2C_SCL, I2C_SDA), System Reset, and 8 dedicated power rail lines (RAIL_1_VOUT – RAIL_8_VOUT) plus ground domains.
  • Mechanical Geometry & CAD: Pre-defined PCB edge cuts (Edge.Cuts), connector placement, mounting references, and 3D CAD STEP model (board.step).
  • Shared Library Integrations: Pre-linked sym-lib-table and fp-lib-table pointing to the shared OSUSat library repository (shared/kicad/).

Instructions for Use

  1. Create a new project from this template when designing a new subsystem card or test fixture for the OSUSat backplane.
  2. Use the Inter-Board-Connector sheet instance to interface your card to the backplane signals.
  3. Add custom payload, sensor, or power circuits on top-level or new sub-sheets.
  4. Verify signal routing and power budgets against system ICD specifications.
